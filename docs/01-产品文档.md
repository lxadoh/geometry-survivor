## 1. 游戏概述

一句话定位：**点开链接就玩的网页小游戏——你控制一个几何图形，在怪物潮中活得更久，每次升级都能"三选一"，每局都组合出不一样的强力玩法。**

- 类型参照：《吸血鬼幸存者》《弹壳特攻队》的极简版。
- 核心卖点：
  1. 上手零门槛：只管移动，武器全自动开火；
  2. 肉鸽随机性：每局升级三选一，组合千变万化，重复可玩性高；
  3. 碎片时间友好：单局 5~10 分钟，死了立刻重来；
  4. 极简美术自成一派：干净的几何风格 + 爽快的打击反馈。

## 2. 目标用户与使用场景
- 目标用户：通过链接访问的休闲玩家（电脑或手机浏览器打开即玩，包含大量非传统玩家）。
- 使用场景：通勤、课间、排队等碎片时间；手机触屏单手操作，电脑键盘操作。
- 核心体验关键词：爽快割草、走位求生、越战越强、随机惊喜。

## 3. 核心玩法循环

```
摇杆走位躲避 ──▶ 武器自动攻击怪物 ──▶ 怪物死亡掉经验宝石
     ▲                                        │
     │                                        ▼
更强的下一波 ◀── 携带新build继续战斗 ◀── 拾取宝石 → 升级三选一
     │
     ▼
  最终死亡 → 结算页（存活时间/击杀/等级 + 历史纪录）→ 再来一局
```

单局节奏目标：
- 第 1 分钟：熟悉操作，轻松割草；**开局 20 秒内发生第一次升级**（快速给爽点）；
- 第 2~4 分钟：压力上升，出现快速怪/坦克怪，升级开始有取舍；
- 第 5 分钟之后：高压期，怪潮密度大增，考验 build 强度；
- 目标死亡时间 5~10 分钟：死得不够爽不行，活得太久也不行。

## 4. MVP 玩法细节（P0）

### 4.1 操作
- **电脑**：键盘 WASD 或方向键控制移动方向。
- **手机**：手指按住屏幕任意位置拖动即出现虚拟摇杆，控制移动方向；松开即停。
- **攻击全自动**：玩家不控制攻击，只负责走位（该品类的核心减法，也是小白玩家的舒适区）。

### 4.2 角色与升级选项池（P0：武器 5 + 被动 5）

玩家为白色圆形；初始武器「飞刃」。武器可被重复选中以升级（LV1→LV5，提升伤害/弹数等）。

| 类型 | 名称 | 效果 |
|---|---|---|
| 武器 | 飞刃（初始） | 自动向最近的敌人发射贯穿飞刃；2 级解锁弹射（命中后跳向下一个敌人再打一次），此后每升一级弹射次数 +1，5 级巨型化 |
| 武器 | 环绕球 | 球体围绕玩家旋转，接触伤害；升级增加球数与环绕半径 |
| 武器 | 散射弹 | 定时向随机方向扇形发射子弹，升级加数量/伤害/体积 |
| 武器 | 闪电 | 每隔数秒劈中屏幕内 1~3 个随机敌人 |
| 武器 | 冲击波 | 周期性以玩家为中心释放一圈范围伤害 |
| 被动 | 攻击力+ | 全武器伤害 +20%（可叠加） |
| 被动 | 攻速+ | 全武器触发间隔 -15%（可叠加） |
| 被动 | 移速+ | 移动速度 +10%（可叠加） |
| 被动 | 最大生命+ | 最大生命 +20 并回满该数值 |
| 被动 | 拾取范围+ | 经验宝石吸取范围 +30%（可叠加） |

> 具体数值在 M1 里程碑实测后调整（数值表见 §7）。

### 4.3 怪物与波次（P0 三种怪）

| 怪物 | 形状 | 行为 | 定位 |
|---|---|---|---|
| 杂兵 | 小三角形 | 直线追向玩家 | 数量多、单体弱 |
| 快速怪 | 尖长三角形 | 速度快、成群出现 | 逼迫玩家走位 |
| 坦克怪 | 大正方形 | 慢速、高血量、近身 | 挡路、制造压迫感 |

- 刷怪方式：从屏幕边缘外持续生成；数量与强度随时间增长（曲线见 §7）。
- MVP 不做精英怪与 Boss（放 P1）。

### 4.4 经验与升级
- 怪物死亡掉落经验宝石（小菱形），玩家靠近自动吸取。
- 经验满 → **游戏暂停** → 弹出三选一面板（从选项池随机抽 3 个不重复选项）→ 选择后继续战斗。

### 4.5 生命与死亡
- 玩家被怪物碰撞扣血，受击后短暂无敌帧；血条显示于角色头顶与 HUD。
- 血量归零 → 结算页：本局存活时间、击杀数、最终等级、历史最高纪录。

### 4.6 场地
- 固定边界大场地（约 4~6 屏大小），摄像机跟随玩家。MVP 不做无限地图（放 P1 讨论）。

## 6. 界面清单（P0 共 4 个界面）
1. **首页**：游戏 Logo、开始按钮、历史最高纪录展示；
2. **游戏 HUD**：血条、等级与经验条、存活时间、击杀数；
3. **升级三选一弹窗**：暂停游戏，三张选项卡片，点击即选；
4. **结算页**：本局数据 + 历史纪录 + 「再来一局」「回首页」。

## 7. 数值框架初稿（占位，M1 实测调整）

角色基础属性：
- 生命 100；移速 180 px/s；拾取范围 90 px；受击无敌 0.85 秒；初始等级 LV1。

成长公式（t = 游戏进行分钟数，N = 目标等级）——**两阶段曲线**：
- 升级所需累计经验：`5 + (N-1) × 7`（前几级十几秒一级，逐渐变慢）；
- 刷怪频率：每秒 `1.0 + 0.55t` 只；同屏上限开局 150，3 分钟后每分钟 +8，最高 240；
- 怪物 HP：基础值 × `(1 + 0.32t + 0.25(t-5)²)`；怪物伤害：基础值 × `(1 + 0.17t + 0.06(t-5)²)`——前 5 分钟线性温和，之后平方级加速；
- 怪物比例随时间向快速怪/坦克怪倾斜（8 分钟后：杂兵 38% / 快速 42% / 坦克 20%）。

平衡原则：**两阶段曲线**——前 5 分钟线性成长保证爽感，5 分钟后怪物强度平方级碾压玩家成型 build，终局自然到来（目标死亡时间 8~12 分钟）。
武器升级只加伤害/数量/体积/范围等属性，**不含攻速**（攻速专属「攻速+」被动，避免升级路线重复）。

## 8. 美术与反馈规范（几何风）
- 形状语言：玩家=圆形；杂兵=三角形；快速怪=尖长三角；坦克怪=方形；子弹=线段/小圆；宝石=小菱形。
- 色彩语言：玩家与 UI=白/蓝；敌人=红/橙色系；经验宝石=绿色。
- 反馈手感：受击闪白、命中小粒子、微量击退、怪物死亡爆裂粒子、升级弹窗动效、玩家受伤时屏幕边缘红闪 + 轻微震动。
- 音效：P0 不做；P1 加入简单合成音效。
