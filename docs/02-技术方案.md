| 项目 | 内容 |
|---|---|
| 文档版本 | v2.0（2026-09-03，平台改版） |
| 形态 | 纯网页游戏（HTML5 Canvas + JavaScript） |
| 托管 | GitHub Pages（免费静态托管，git push 即上线） |
| 后端 | 无（纯单机） |

## 1. 选型结论与理由（2026-09-03 用户确认改版）

| 项 | 结论 |
|---|---|
| 形态 | 纯 HTML5 网页：零游戏引擎、零构建工具 |
| 语言 | JavaScript（ES Module，浏览器原生支持） |
| 美术 | Canvas 2D 代码绘制几何图形，零图片素材 |
| 托管/发布 | GitHub Pages：推送即上线，无审核 |
| 存档 | 浏览器 localStorage |
| 后端 | 无 |

改版理由（对应决策记录 2026-09-03）：
- 发布平台由微信小游戏改为 GitHub Pages 后，原引擎 Cocos Creator 的核心优势（微信一键构建）不再需要；
- 本项目零图片、全代码绘制，不需要引擎的可视化编辑能力；
- **零安装**：不装 Cocos Dashboard/编辑器、微信开发者工具，也不需要 Node.js——开发机有浏览器即可；
- **零构建**：直接用浏览器原生 ES Module，改完代码刷新页面即生效，调试反馈最快；
- 部署即 git push，回滚、迭代都简单。

## 2. 开发环境清单（M0 阶段）

| 工具 | 作用 | 说明 |
|---|---|---|

## 3. 工程结构规划

```
index.html            入口页面（全屏 Canvas）
css/style.css         页面样式（背景、禁止滚动/缩放）
js/
  main.js             入口：初始化、游戏主循环
  core/               GameRoot 总管理、Input（键盘+触屏摇杆归一）、SaveManager、ObjectPool、Camera
  entities/           Player、Enemy（三种怪共用脚本+参数区分）、Bullet、Gem
  weapons/            WeaponBase 及 5 种武器、PassiveSkill 被动
  ui/                 HUD、升级三选一、结算页、首页
  data/               数值配置表（武器/怪物/波次成长，JS 常量表）
（无图片目录——所有图形用 Canvas 运行时绘制）
```

关键约定（改版前后一致）：
- **数值全部集中在 `data/` 配置表**：调平衡不动逻辑代码；
- 怪物、子弹、宝石**全部走对象池**，禁止频繁创建/销毁对象。

## 4. 关键技术点

### 4.1 性能（幸存者like 的生命线）
- 对象池管理怪物/子弹/宝石；
- 同屏怪物上限 150，超出延迟生成；低端机自动降为 80；
- 碰撞检测：自研简易方案（圆形/矩形包围盒 + 空间网格分区加速），不引入物理引擎；
- 主循环 requestAnimationFrame，帧率无关的 dt 步进；
- 性能目标：中端手机 60fps、低端机 30fps、电脑普遍 60fps+。

### 4.2 输入（双操控归一）
- 电脑：键盘 WASD / 方向键；
- 手机：触屏虚拟摇杆（按下任意位置即出现）；
- 两种输入统一输出为一个"移动方向向量"，游戏逻辑只认这个向量，不关心来源。

### 4.3 画面适配
- 逻辑分辨率 + 等比缩放自适应：电脑横屏宽视野、手机竖屏窄视野自动适配；
- HUD 按安全区布局，避开手机状态栏/圆角。

### 4.4 存档
- 封装统一存档接口，仅用浏览器 localStorage（无需再区分微信环境）；
- 存档内容：历史最高纪录（存活时间/击杀/等级）+ 最近 10 局战绩（P1 本地战绩本）；
- 注意：localStorage 属浏览器本地数据，清缓存会丢失——网页游戏常态，结算页注明"本地存档"。

### 4.5 包体与加载
- 零图片素材 + 零依赖库，整个游戏预计 < 200KB，秒开；
- GitHub Pages 自带全球 CDN，无需额外优化。

## 5. 发布流程（GitHub Pages）

1. GitHub 新建公开仓库（仓库名届时与用户确认）；
2. 将网页文件推送到仓库；
3. 仓库 Settings → Pages → 选择 main 分支开启；
4. 访问 `https://<用户名>.github.io/<仓库名>/` 即为游戏地址；
5. 之后每次更新游戏：推送新代码即自动生效，无需任何审核。

## 6. 风险与对策

| 风险 | 对策 |
|---|---|
| 低端手机同屏怪物卡顿 | 对象池 + 同屏上限 + 粒子效果分级，M2 手机浏览器实测 |
| 无引擎需自研渲染/碰撞 | 玩法为 2D 几何图形，Canvas 2D 完全够用；碰撞用简单圆/矩形 |
| 数值不平衡（过难/过易） | 数值集中在配置表；M1、M2 各做一轮实测调参 |
| localStorage 被清导致丢档 | 网页游戏常态，界面注明；未来可选导出/导入存档码 |
| GitHub Pages 国内访问速度 | 一般可接受；备选方案：套国内可达 CDN 或换托管，超出 MVP 范围，遇到再议 |
