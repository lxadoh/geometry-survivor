## M1 计划（核心战斗可玩）
目标：浏览器打开即能完整玩一局（移动 → 战斗 → 升级三选一 → 死亡结算）。
1. 游戏骨架：全屏 Canvas、主循环、数值配置表；
2. 玩家移动（键盘 + 触屏摇杆）与摄像机跟随；
3. 初始武器「飞刃」+ 3 种怪物 + 碰撞与死亡掉宝石；
4. 经验升级 → 三选一（先上选项池中的武器/被动各若干）→ 死亡结算页。

> ZCode 会提供分步指引；过程中遇到需要选择的地方，会列方案供用户选择。
